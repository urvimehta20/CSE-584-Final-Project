## Decision rules

These rules are applied mechanically in `REPORT.md` from numbers in `followup_results.json`.

### "B beats A on retrieval"

The paired difference in Recall@k (B − A) has a 95% bootstrap CI entirely above 0.

- Difference is computed per resampled question (cluster bootstrap), then averaged.
- The CI is the 2.5th and 97.5th percentiles of 2,000 question-cluster bootstrap replicates.
- The rule is evaluated separately for each setting (R, G), each B variant (B-leaf, B-pillar), and each k in that setting’s k-set. A MET/NOT MET call is made for each; the verdict rule in the report specifies which calls count.

### "B saves meaningful tokens"

At equal recall, B needs ≥15% fewer prompt tokens than A, AND the paired CI of the relative saving excludes 0.

- Relative saving for a question (or query, in setting R) is `(tokens_A − tokens_B) / tokens_A`.
- The mean is taken only over units where both A and B reach the target recall r.
- The 95% CI is a paired cluster bootstrap over questions (2,000 resamples).
- The rule is evaluated separately for each setting (R, G), each B variant, and each r ∈ {0.5, 0.8, 1.0}. A MET/NOT MET call is made for each; the verdict rule in the report specifies which calls count.

### "Pruning errors fall on hard evidence"

Among gold chunks, those pruned by B have significantly worse A-ranks than those kept (one-sided Mann–Whitney U, p < 0.05), AND at most 10% of pruned gold was in A's top-10.

- “Worse A-ranks” means higher rank numbers / higher rank percentiles (1 = best).
- The Mann–Whitney U is one-sided: pruned percentile > kept percentile.
- The 10% check is `# {pruned gold with A-rank ≤ 10} / # {pruned gold}`.
- The rule is evaluated separately for each setting (R, G) using that setting’s frozen best B.

## Other locked choices

- Gold threshold: relevance ≥ 2.
- Cross-fitting: 2-fold over the 16 core questions, split by question, seed 42; tune on one half, evaluate on the other, then swap. Every core question is held out exactly once. Pooled held-out results are primary. The original pilot core-test split is also reported.
- Bootstrap: resample questions, not queries; 2,000 resamples; paired differences use the same resampled questions for both configs.
- Human topic labels are used only if `data/question_topics.csv` exists and is filled. They are never invented by code. The empty template is `data/question_topics_TEMPLATE.csv`.
- Valid `human_pillar` values: `E`, `S`, `G`.
- Valid `human_leaves` values (semicolon-separated): `e_physical_climate_risk`, `e_transition_risk`, `e_climate_adaptation`, `e_ghg_emissions`, `e_energy`, `e_water`, `e_biodiversity`, `e_waste`, `s_workforce`, `s_health_safety`, `s_community`, `g_board_oversight`, `g_risk_management`, `g_ethics`.
